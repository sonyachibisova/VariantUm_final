ТРЕБОВАНИЯ:
1. Сохрани структуру эталона: число заданий в варианте = числу заданий в эталоне, порядок и тип — те же.
2. Сохрани форму ответа каждого задания (число, формула, выбор, развёрнутый текст — как в эталоне).
3. Если градация EQUAL — сохрани сложность и число шагов решения, как в соответствующем задании эталона.
4. Если градация ASCENDING — постепенно усложняй варианты (больше шагов, больше абстракции).
5. Если градация CUSTOM — следуй заданным уровням сложности для каждого варианта.
6. Не используй «красивых» чисел, которые делают вычисление устным.
7. Ответы на одно и то же задание в РАЗНЫХ вариантах должны быть РАЗНЫМИ.
8. Не повторяй формулировки эталона дословно — варьируй язык согласно типам вариации.
9. Если учитель дал дополнительные указания — выполняй их в приоритете.
10. ЯЗЫК: пиши задания НА ТОМ ЖЕ ЯЗЫКЕ, что и эталон. Если эталон на английском — все варианты должны быть ПОЛНОСТЬЮ на английском. Никогда не смешивай языки внутри одного задания.

ФОРМУЛЫ И МАТЕМАТИКА:
- Любую математическую формулу, уравнение, дробь, степень, индекс, химическую формулу или физическую
  величину записывай в синтаксисе LaTeX.
- Инлайн-формулы оборачивай в одиночные доллары: $x^2 + 2x - 3 = 0$.
- Выносные (отдельной строкой) формулы — в двойные доллары: $$\frac{a}{b} = \frac{c}{d}$$.
- Обычный текст условия оставляй как есть, в LaTeX оборачивай ТОЛЬКО математику.
- Используй ТОЛЬКО команды, совместимые с KaTeX: \frac, \sqrt, \sum, \prod, \int, \lim, \vec, \overline, \hat, \bar, \alpha…\omega, \Delta, \Sigma, \Phi, \Pi, \Omega, \cdot, \times, \div, \pm, \leq, \geq, \neq, \approx, \equiv, \perp, \parallel, \infty, \to, \Rightarrow.
- ЗАПРЕЩЕНО: любые \begin{...}…\end{...} (в том числе \begin{align}, \begin{equation}, \begin{array}). ЗАПРЕЩЕНО: \mathbb, \mathcal, \mathfrak, \operatorname.
- Кириллицу пиши ВНЕ формул: не оборачивай русский текст в $…$ и не используй \text{кириллица}.
- Внутри инлайн-формулы $…$ перенос строки НЕДОПУСТИМ — одна формула = одна строка.

ГРАФИКИ ФУНКЦИЙ:
- Если задание про функции, графики, построение функций (алгебра, математический анализ, физика) —
  ВСТАВЛЯЙ маркер графика прямо в текст задания или ответа:
  [ФУНКЦИЯ: {"fn":"x^2-2*x+1","xMin":-3,"xMax":3}]
- fn: строка с функцией (используй: x, ^(степень), *, /, +, -, sin, cos, tan, sqrt, abs, ln, pi, e)
- xMin, xMax: границы диапазона оси X (числа)
- Пример: [ФУНКЦИЯ: {"fn":"sin(x)","xMin":-3.14,"xMax":3.14}]
- Пример: [ФУНКЦИЯ: {"fn":"1/x","xMin":-5,"xMax":5}]
- yMin, yMax: опционально, границы оси Y (если не указать — автомасштаб)
- ВАЖНО: маркер [ФУНКЦИЯ: ...] — это НЕ формула! НЕ оборачивай его в $ или $$. Пиши как есть.

ГРАФИК ДОЛЖЕН БЫТЬ РЕШАЕМЫМ И ЧИТАЕМЫМ (это критично!):
- Подбирай коэффициенты так, чтобы ВСЕ ключевые точки задания (вершина параболы, точки пересечения с осями,
  целевые значения) попадали в ЦЕЛЫЕ координаты. Пример: вершина параболы $y=x^2-4x+3$ в точке (2,-1) — целые.
  НЕ давай функции вроде $y=x^2-3x+1$ (вершина в 1.5; −1.25) — по такому графику ответ не считывается.
- Диапазон [xMin, xMax] выбирай небольшим и симметричным вокруг ключевых точек (обычно от -5..-3 до 3..5),
  чтобы шаг сетки был ровно 1 (целые деления). Не задавай широкие диапазоны (например, -100..100) — крупный
  шаг делает график нечитаемым.
- Если по графику нужно определить точку/значение — убедись, что эта точка лежит на пересечении линий сетки
  (целые x и y), иначе задание нерешаемо.
- Линейные функции: бери целые угловой коэффициент и сдвиг ($y=2x-3$), точки пересечения с осями — целые.

СИСТЕМЫ УРАВНЕНИЙ И НЕРАВЕНСТВ:
- Систему ВСЕГДА оформляй окружением cases в выносной формуле, чтобы фигурная скобка и строки отрисовались:
  $$\begin{cases} 2x + y = 5 \\ x - y = 1 \end{cases}$$
- Систему неравенств — так же: $$\begin{cases} x + 2 > 0 \\ 3 - x \geq 0 \end{cases}$$
- НИКОГДА не пиши систему обычным текстом в фигурных скобках ({ ... ; ... }) и не разбивай её на строки вне cases —
  иначе скобка не отрисуется. Знаки неравенств — командами LaTeX: \leq, \geq, \neq, \lt, \gt.

ТАБЛИЦЫ:
- Таблицы оформляй как Markdown-таблицы (| ... | ... |).

ТЕСТ С ВАРИАНТАМИ ОТВЕТА:

ПОЛЯ ДЛЯ АВТОПРОВЕРКИ (обязательно заполни для каждого задания):
- "expectedAnswer" — САМЫЙ КОРОТКИЙ правильный ответ, который ученик должен написать:

  - для задач с числовым ответом: только число без единиц (например: "12" или "3.5")
  - для заданий с несколькими частями (а/б/в): ответы через "; " (например: "12; 3.5" или "а; параллельные")
  - для заданий с вставкой пропущенного слова/буквы: только вставляемый фрагмент (например: "о" или "параллельные")
  - для заданий с текстовым ответом из нескольких слов: ключевое слово или короткая фраза
  - для OPEN_QUESTION: null
- "answerHint" — подсказка для ученика о формате ответа, показывается в онлайн-форме под полем ввода:
  - для TEST: null (форма сама покажет варианты)
  - для OPEN_QUESTION: null
  - для числовых ответов: "целое число", "число" или "число в см" и т.п.
  - для ответов одним словом/буквой: "одна буква", "одно слово", "слово или словосочетание"
  - для заданий с несколькими частями (а/б/в): формат каждой части, например "целое число" — форма покажет его под каждым подпунктом
  - примеры: "целое число", "одна буква", "одно слово", "число в градусах"

ОФОРМЛЕНИЕ ТЕКСТА ЗАДАНИЙ:
