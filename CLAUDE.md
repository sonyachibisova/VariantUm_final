### Реализованы — итерация надёжности и geometry-чертежей

**Мультимодельность + отказоустойчивость (`GigaChatClient`):**
- Три конфигурируемые модели: Lite → анализ/очистка/рекомендации, Pro → генерация/правка, Max → опц.
- `completion(prompt, temp, model)` — перегрузка с явной моделью
- `completion(prompt, temp)` — автофолбэк: Pro → 402 → Lite (бесплатная `GigaChat`)
- `AnalyzeService`, `TextCleanupService`, `RecommenderService` → Lite
- Конфиг: `.env` `GIGACHAT_MODEL_LITE=GigaChat`, `GIGACHAT_MODEL_MAX=GigaChat-2-Pro`
- `docker-compose.yml` — `GIGACHAT_MODEL_LITE` и `GIGACHAT_MODEL_MAX` переданы в контейнер
- `application.yml` — исправлен default `model-lite: GigaChat` (было несуществующее `GigaChat-2-Lite`)
- ⚠️ `GigaChat-2-Lite` — несуществующее имя модели (404). Lite-модель = `GigaChat` (бесплатная)

**Устойчивый парсинг JSON (`LlmJsonUtil`):**
- Базовая модель `GigaChat` пишет LaTeX с одиночными `\` внутри JSON (невалидный escape)
- `sanitizeJsonEscapes()` — конечный автомат: удваивает невалидные `\`, экранирует буквальные `\n`/`\r`/`\t`
- Двухпроходный парсинг: попытка 1 — raw JSON, попытка 2 — после починки

**SVG-рендер геометрических фигур — 6 типов:**
- GigaChat возвращает структурированный `figure: {}` в каждом задании (поле в JSON ответа)
- Промпты 2 и 3 обновлены: инструкции по генерации figure-JSON с примерами
- `GeneratedModels.GeneratedTask` + `TaskResponse` — поле `figure: Map<String, Object>`
- Данные сохраняются в `tasks.metadata_json` (существующая JSONB-колонка, миграция не нужна)
- `FigureSvgRenderer.java` — inline SVG для экспорта: triangle, quadrilateral, circle, coordinatePlane, numberLine, **geometry**
- `FigureSvg.tsx` — React SVG-рендерер (те же 6 типов), используется в `RichText.tsx`
- `geometry` — универсальный тип: именованные точки (x,y), отрезки "A-B", маркеры прямого угла, доп. метки
  - Сегмент-aware позиционирование меток: метка отталкивается от входящих рёбер, а не от центроида
  - Двойной рендер текста: белый слой (обводка) + цветной слой = метки читаемы поверх линий
- Типы в `types/api.ts`: `FigureData` union = `'triangle'|'quadrilateral'|'circle'|'coordinatePlane'|'numberLine'|'geometry'`
