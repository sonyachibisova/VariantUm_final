## Как продолжить работу с Claude (инструкция)

У тебя сейчас открыт диалог в claude.ai, где я создавал документы внутри **Проекта**. Чтобы потом перейти к разработке кода и сохранить весь этот контекст — есть несколько путей. Выбирай по ситуации.

### Вариант 1. Остаться в claude.ai в этом же Проекте (самый простой)

Все созданные документы я положил в `/mnt/user-data/outputs/`. Файлы из этой папки **не сохраняются автоматически** в Проект — это рабочая папка моего контейнера, которая сбрасывается между разговорами.

**Что нужно сделать тебе:**
1. Скачай все 8 файлов из этого ответа (там кнопки скачивания)
2. Зайди в свой Проект «ВариантУм» в claude.ai (тот же, где сейчас лежат `Требования.pdf`, `Кейсы.pdf` и др.)
3. Загрузи туда все 8 .md файлов как **файлы проекта** (`Project knowledge`)
4. После этого в любом новом разговоре внутри этого Проекта я буду видеть все 8 документов + исходные PDF от организаторов автоматически

**Преимущества:** не нужно ничего устанавливать, контекст всегда со мной.
**Минусы:** нет реального доступа к локальной файловой системе твоего компьютера, я не могу прямо запустить код, который пишу.

---

### Вариант 2. Перейти в Claude Code (для реальной разработки)

Claude Code — это CLI-инструмент, который запускает меня прямо в твоём терминале с доступом к файлам репозитория. Когда начнётся написание кода — это правильный путь.

**Шаги:**

1. **Установка Claude Code** (нужен Node.js 18+):
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. **Создай папку проекта на компьютере и инициализируй git:**
   ```bash
   mkdir variantum
   cd variantum
   git init
   ```

3. **Перенеси документацию в проект:**
   ```bash
   mkdir docs
   # скопируй сюда все 8 .md файлов
   ```

4. **Создай файл `CLAUDE.md` в корне проекта** — это специальный файл, который Claude Code читает автоматически в каждом разговоре. Содержание:
   ```markdown
   # ВариантУм — контекст проекта для Claude
   
   Перед началом любой работы прочитай эти файлы из папки `docs/`:
   - `01_Анализ_проекта_ВариантУм.md` — общее понимание
   - `04_Техническое_задание.md` — что делать
   - `05_API_спецификация.md` — контракт API
   - `06_Схема_БД_и_структура_проекта.md` — структура БД и репозитория
   - `07_Промпты_для_GigaChat.md` — тексты промптов
   
   ## Контекст
   - Хакатон СберОбразования, кейс 4
   - Стек: Java 21 + Spring Boot 3.2 (backend), React + TypeScript (frontend)
   - LLM: GigaChat-Pro
   - Сдача: 28 мая 2026
   
   ## Текущий этап
   <обнови это поле по мере прогресса: «инициализация репозитория»,
   «backend: парсеры», «frontend: страница входа» и т.д.>
   
   ## Правила работы
   - Когда пишешь backend-код — всегда соблюдай структуру из документа 06
   - При добавлении нового API endpoint — обнови документ 05
   - Промпты к GigaChat хранятся в `backend/src/main/resources/prompts/`,
     синхронизируй с документом 07
   ```

5. **Запусти Claude Code в папке проекта:**
   ```bash
   claude
   ```

   Я открою сессию прямо в этой папке, прочитаю `CLAUDE.md`, прочитаю файлы из `docs/`, и буду готов начинать разработку с полным контекстом.

6. **Первая команда, которую можно дать:**
   ```
   Прочитай документы в docs/ и инициализируй структуру monorepo
   по документу 06. Создай pom.xml для backend, package.json для frontend,
   docker-compose.yml и .env.example.
   ```

**Преимущества:** я могу читать и писать файлы напрямую, запускать команды (mvn, npm, docker), видеть результат компиляции и тестов, рефакторить код, исправлять ошибки сразу.
**Минусы:** нужна установка, нужен API-ключ Anthropic (если у тебя есть подписка Pro — она же включает Claude Code в большинстве регионов).

### Вариант 3. Гибрид (что я бы рекомендовала тебе)

1. Сейчас, до начала кодинга — **остаёмся в claude.ai с Проектом**:
   - Загружаешь 8 файлов в Проект как знания
   - Тут мы можем подправить документы, обсудить продуктовые решения, нарисовать дополнительные схемы, набросать макеты, написать опросник для интервью с учителями, подготовить презентацию
   - Это удобнее для нетехнической работы

2. Когда переходим к написанию кода (день 1 разработки, ~20 мая) — **переключаешься на Claude Code**:
   - Создаёшь репозиторий на компьютере
   - Кладёшь туда документацию
   - Я работаю с файлами напрямую и пишу реальный код
   - Этот claude.ai-разговор используй для «больших вопросов» и продуктовых решений, а Claude Code — для кодинга

3. **Сохрани этот разговор**: в claude.ai открой меню разговора (три точки) → закрепи или дай осмысленное название. Если что-то понадобится найти в этой переписке через неделю — не потеряешь.
