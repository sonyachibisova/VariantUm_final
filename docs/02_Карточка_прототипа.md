# Карточка прототипа — ВариантУм

> Заполнено по форме из материалов хакатона СберОбразования

---

## Название идеи

**ВариантУм** — ИИ-генератор вариантов школьных заданий с сохранением дидактической сложности.

---

## Описание идеи (Что это?)

ВариантУм — это веб-сервис для учителей 1–11 классов, который генерирует школьные задания и их варианты двумя способами:

**Режим A — «По эталону».** Учитель загружает готовое задание (вставляет текст, прикрепляет PDF/DOCX или фотографирует страницу методички), задаёт параметры вариации (что менять: числа, контекст, имена, порядок условий) и количество нужных вариантов. Сервис анализирует структуру задания, выделяет инвариантные элементы (то, что нельзя трогать без изменения дидактической цели) и вариативные элементы (числовые данные, имена, ситуации), и через GigaChat генерирует новые варианты.

**Режим B — «С нуля по критериям».** Учитель не загружает ничего, а описывает желаемый результат: предмет, класс, тема, тип задания, количество вариантов, количество заданий в варианте, время на выполнение, целевая сложность. Сервис генерирует комплект с нуля. Этот режим нужен, когда у учителя нет под рукой исходного материала, но требуется срочно сделать самостоятельную или контрольную.

**Общие возможности обоих режимов:**

- **Дополнительный промпт от учителя** на любом этапе — естественным языком уточнить, что нужно («сделай задачи про спорт», «избегай отрицательных чисел», «добавь геометрический пример»).
- **Градация сложности** — варианты могут быть одинаковой сложности (классический случай для контрольной), либо возрастающей сложности (для дифференцированной работы: слабые → сильные ученики), либо по произвольной шкале, которую задаёт учитель.
- **Три способа правки**: ручная правка в WYSIWYG-редакторе с поддержкой формул; промпт-правка одного варианта («сделай реалистичные числа в задаче 3»); промпт-правка всего комплекта одной командой («замени все автомобили на поезда»).
- **Параллельный просмотр** вариантов с подсветкой различий, перегенерация любого варианта отдельно.
- **История версий** комплекта — откат к предыдущему состоянию.
- **Экспорт в PDF и DOCX** с настраиваемыми полями ФИО/класс/дата и отдельным комплектом ответов для учителя.

**Задачи для ИИ (GigaChat):**
1. **Анализатор задания** (Режим A) — определяет предмет, класс, тип, уровень сложности, выделяет вариативные и инвариантные компоненты эталона
2. **Генератор по эталону** (Режим A) — создаёт N вариантов, сохраняя число шагов решения и тип когнитивной нагрузки
3. **Генератор с нуля** (Режим B) — создаёт комплект заданий по критериям с учётом школьной программы для указанного класса
4. **Валидатор сложности** — проверяет, что сгенерированные варианты соответствуют целевой сложности (одинаковой или градации)
5. **Оценщик времени** — прогнозирует время решения каждого варианта и комплекта
6. **Промпт-редактор одного варианта** — применяет указания учителя к конкретному варианту, сохраняя сложность
7. **Промпт-редактор комплекта** — применяет указания учителя ко всем вариантам единообразно
8. **Рекомендатор** — анализирует комплект, предлагает улучшения учителю

## Сегменты потребителей (Для кого?)

### Основной сегмент: учителя-предметники 1–11 классов

**Портрет 1. «Мария Петровна, 52 года, учитель математики»**
- Стаж 28 лет, работает в обычной городской школе
- Ведёт 6 классов, в неделю проводит 24 урока
- Готовит контрольные раз в 2–3 недели по каждому классу
- Привычки: распечатывает варианты на принтере, рассаживает класс по рядам
- Боли: на 4 варианта контрольной уходит вечер субботы; вручную поменянные числа создают «красивые» совпадения, ученики быстро вычисляют логику
- Технологические привычки: уверенно пользуется Word и Excel, ChatGPT не доверяет
- **Цель использования ВариантУм:** освободить субботний вечер, гарантировать одинаковую сложность

**Портрет 2. «Алексей Иванович, 38 лет, учитель физики»**
- Стаж 14 лет, лицей с углублённым изучением
- Любит сложные авторские задачи, есть личный архив из ~500 эталонов
- Боли: к одному эталону нужно 5 вариантов разного контекста (механика → электричество → оптика), а не просто «другие числа». Это сложнее всего сделать вручную
- Технологические привычки: продвинутый пользователь, пробовал ChatGPT, разочарован качеством
- **Цель использования ВариантУм:** масштабировать свой архив, генерировать вариации сохранив авторский стиль

**Портрет 3. «Елена Сергеевна, 29 лет, учитель английского»**
- Стаж 6 лет, начальная и средняя школа
- Делает много раздаток с лексическими упражнениями
- Боли: однотипные упражнения (gap-fill, matching) на новые слова. Каждый раз — заново
- Технологические привычки: активно использует Я.GPT, Quizlet, Wordwall
- **Цель использования ВариантУм:** быстро мультиплицировать лексические упражнения, добавив поля для ФИО и оценки

### Вторичный сегмент
- Методисты школ и муниципальных управлений (создание банков заданий)
- Репетиторы (индивидуальные варианты для разных учеников)
- Преподаватели колледжей и СПО
- Авторы методических пособий (массовая мультипликация)

## Проблемы, деятельность, процесс (Для чего?)

### 1. Вид деятельности
**Подготовка контрольно-измерительных материалов и раздаточных листов с заданиями.** Конкретно:
- Создание нескольких вариантов одной контрольной/самостоятельной/домашней работы
- Подготовка индивидуальных вариантов для пересдач и работы с отстающими
- Создание раздаточных материалов с упражнениями одинаковой сложности
- Поддержание персонального архива заданий с возможностью мультипликации

### 2. Процесс, который оптимизируется
**Подготовка к проведению контроля знаний.** Сейчас в цикл подготовки контрольной работы у учителя входит:
1. Выбор эталонной задачи из учебника/методички
2. Ручная вариация: замена чисел, имён, контекста
3. Проверка корректности каждого варианта (решение в уме или на черновике)
4. Проверка одинаковости сложности
5. Оформление в Word
6. Печать

ВариантУм оптимизирует **шаги 2–5**, сокращая их с 1–3 часов до 2–5 минут. Шаги 1 (выбор) и 6 (печать) остаются за учителем, но шаг 6 упрощается за счёт готовых PDF-шаблонов с полями.

### 3. Участники, на которых влияет инструмент

| Участник | Прямой/косвенный | Эффект |
|---|---|---|
| **Учитель** | Прямой | Экономия 5–10 часов в неделю, снижение выгорания, выше качество контроля |
| **Ученик** | Косвенный | Получает варианты с реально разной сложностью, исключающие списывание. Меньше «лотереи»: всем достаются равные по нагрузке варианты |
| **Завуч / методист** | Косвенный | Видит, что учитель использует современные инструменты; качественные КИМы для отчётности |
| **Родитель** | Косвенный | Ребёнок получает более качественные и индивидуализированные задания, меньше списывания в классе |

## Образ продукта (Какой и как работает?)

### Как будет работать

**Базовый сценарий за 5 шагов:**

1. **Вход.** Учитель регистрируется (email + пароль или SberID в будущем), попадает в личный кабинет. При первом входе запускается онбординг-тур (react-joyride): 30-секундная экскурсия по интерфейсу с подсветкой ключевых кнопок. Под кнопкой «Помощь» висит 2-минутное видео.

2. **Загрузка эталона.** Главный экран — большое поле в центре с тремя вкладками: «Вставить текст», «Загрузить файл», «Сфотографировать». Поддерживаются TXT, PDF, DOCX, PNG, JPG. Для сканов и фото включается OCR (Tesseract с русской моделью). Учитель видит предпросмотр распознанного текста и может его поправить.

3. **Анализ и параметры.** Сервис вызывает GigaChat для анализа: определяет предмет, класс, тип задания, уровень сложности. Учитель видит результат анализа и может скорректировать его (выпадающими списками). Далее задаёт:
   - количество вариантов (слайдер 2–10)
   - типы вариации (чекбоксы: числа, имена, контекст, порядок условий, лексика)
   - дополнительные опции: «зафиксировать N как 0», «проверить совпадение ответов», «оценить время решения»

4. **Генерация и сравнение.** На экране появляется таблица параллельного сравнения вариантов с подсветкой различий относительно эталона. Сверху лента рекомендаций: «вариант 3 заметно проще — пересоздать?», «время решения комплекта ~15 минут». На каждый вариант — три кнопки: «Редактировать» (открывает WYSIWYG), «Перегенерировать» (только этот), «Удалить».

5. **Экспорт.** Кнопка «Экспортировать комплект» открывает модалку с настройками:
   - Формат: PDF / DOCX
   - Включить ли титульный лист
   - Добавить ли поля: ФИО ученика, класс, дата, оценка, подпись родителя
   - Отдельный PDF с ответами «только для учителя»
   - Раскладка: по одному варианту на лист или по два

Файл скачивается. Комплект автоматически сохраняется в личную библиотеку учителя.

### В чём проявляется персонализация

1. **Персонализация под учителя:** библиотека эталонных заданий привязана к аккаунту, никто другой её не видит. История генераций сохраняется. Со временем сервис учится на правках учителя, что именно он считает «хорошим вариантом» (фишка для версии 2.0).

2. **Персонализация под класс:** учитель указывает класс (1–11) и уровень (базовый/углубленный/олимпиадный), и сервис подбирает соответствующие промпт-стратегии.

3. **Персонализация под ученика:** через генерацию N вариантов один комплект может включать варианты разной сложности для дифференциации работы с отстающими и сильными.

4. **Персонализация формата вывода:** настраиваемые поля для печати, раскладка, добавление логотипа школы и подписи учителя.

## Предполагаемый эффект для пользователей

### Каким будет эффект?

**Для учителя:**
- Сокращение времени подготовки вариантов с **1–3 часов до 2–5 минут** (в 30–60 раз)
- **Гарантия одинаковой сложности** вариантов — снижение «лотерейности» контроля
- Полное отсутствие случайных совпадений ответов между вариантами
- Возможность создавать **больше форм работы** (4 варианта вместо 2, индивидуальные пересдачи)
- Освобождённое время на проверку, индивидуальную работу, методическое развитие

**Для ученика:**
- Равные по нагрузке варианты — справедливость оценки
- Реальная защита от списывания → честный контроль знаний
- Для пересдач — действительно новый вариант, а не «тот же с другими числами»

**Для образовательной системы:**
- Снижение профессионального выгорания учителей
- Рост качества КИМов в обычных школах до уровня лицеев
- Готовность к интеграции в экосистему СберОбразования

### Как измерить эффект

| Метрика | Как измерять | Целевое значение к концу пилота |
|---|---|---|
| **Среднее время на создание комплекта из 4 вариантов** | Замер от загрузки эталона до экспорта PDF | ≤ 5 минут |
| **Уровень удовлетворённости (CSAT)** | Опрос после 3-го использования | ≥ 4.3 из 5 |
| **NPS** | Опрос «порекомендуете коллеге?» | ≥ 40 |
| **Сохранение сложности** | Экспертная оценка методистов на выборке 50 комплектов | ≥ 90% комплектов с одинаковой сложностью |
| **Доля принятых без правок вариантов** | Из всех сгенерированных, сколько прошли «as is» в экспорт | ≥ 70% |
| **Retention 30 дней** | % учителей, вернувшихся через месяц | ≥ 50% |
| **Среднее число генераций на учителя в месяц** | Из логов | ≥ 8 |
| **Время от регистрации до первого экспорта** | Замер по событиям | ≤ 10 минут |

### Какой эффект для персонализации даст инструмент

ВариантУм впервые делает массово доступной **глубокую персонализацию контроля знаний**: вместо «всем одно задание» учитель за минуты получает дифференцированный пакет, где каждый ученик решает свой вариант — но с гарантированно равной сложностью. Это:

1. Делает оценку справедливой (все условия равны)
2. Делает невозможным списывание (нет «правильного ответа», подходящего всем)
3. Открывает возможность индивидуализации (отстающий получает базовый вариант, сильный — продвинутый, и оба в рамках одной контрольной)
4. Высвобождает время учителя именно на то, ради чего он пришёл в школу — **на работу с детьми, а не с бумагами**

### Критерии оценки эффективности инструмента

1. **Воспроизводимость полного сценария** — учитель проходит весь путь от загрузки до экспорта без багов
2. **Качество генерации** — экспертная оценка методистами: сохранена ли сложность, нет ли искажений, нет ли «красивых» совпадений
3. **Гибкость редактирования** — учитель может изменить любой элемент любого варианта
4. **Время до результата** — секунды от старта до готового комплекта
5. **Удобство для возрастных пользователей** — UX-тесты с учителями 50+
6. **Безопасность данных** — никакие материалы учителя не видны другим пользователям
7. **Готовность к интеграции** — стек на Java Spring совместим с инфраструктурой Сбера
