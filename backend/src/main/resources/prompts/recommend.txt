КОМПЛЕКТ:
{project_json}

ПРОВЕРЬ:
1. Есть ли варианты, заметно отличающиеся по сложности от остальных (если градация EQUAL).
2. Есть ли совпадающие или близкие ответы между вариантами.
3. Не слишком ли однообразны типы заданий внутри одного варианта (если M > 1).
4. Соответствует ли заявленное время реальной сложности.
5. Есть ли явные методические недочёты (нереалистичные данные, ошибки в формулировке).
6. Что можно добавить для разнообразия.

ВЕРНИ СТРОГИЙ JSON-СПИСОК РЕКОМЕНДАЦИЙ (от 0 до 5 штук), БЕЗ КОММЕНТАРИЕВ:

{
  "recommendations": [
    {
      "type": "DIFFICULTY_OUTLIER",
      "variantIndex": 3,
      "severity": "WARNING",
      "message": "Вариант 3 заметно проще остальных: 2 шага против 4"
    },
    {
      "type": "ADD_VARIATION",
